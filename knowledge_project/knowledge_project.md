# Knowledge Project: BUDGETIN

Selamat datang di direktori pengetahuan proyek BUDGETIN. Direktori ini berfungsi sebagai otak kedua (second brain) untuk tim pengembang dan Agen AI.

## Tujuan Direktori Ini
Direktori `knowledge_project/` dirancang untuk diindeks oleh tool seperti **Graphify**. Direktori ini menyimpan semua informasi konseptual, panduan gaya (style guide), struktur arsitektur, dan memori jangka panjang proyek.

## Struktur File
- `ingatan.md` : Tempat menyimpan aturan dasar, konteks terkini, dan riwayat keputusan teknis penting. Baca ini setiap memulai tugas.
- `vibe_coding.md` : Panduan filosofis tentang cara kita membangun proyek ini (cepat, minim kode, fokus pada *vibe* dan fungsionalitas).
- `knowledge_project.md` : Daftar isi dan pengantar tentang proyek secara umum.

## Cara Menggunakan (Untuk AI Agents)
Jika kamu merasa kehilangan konteks, jalankan perintah `/graphify knowledge_project/` atau telusuri isi dari file-file di sini untuk menemukan benang merah proyek. Semua agen AI bebas menambahkan atau memodifikasi catatan di dalam direktori ini jika ada pembaruan infrastruktur yang signifikan.
